This file is a template, not a published note.

To add a note by hand:

1. Copy this file to `<slug>.md` (for example `fix-ipv6-dns.md`).
2. Change `title`, `date` and `summary` in the frontmatter.
3. Write the note below the frontmatter.
4. Delete `draft: true` (or set it to `false`).

You can also delete this file if you only use the Learned Importer app.
